Matrix puppeting bridge for Google Messages, based on the official [mautrix-gmessages](https://github.com/mautrix/gmessages) bridge (Go, bridgev2).

It bridges the SMS, MMS and RCS conversations of an **Android** phone using the Google Messages app, the same way as messages.google.com. The phone must stay online.

The bridge is a Synapse application service and relies on a PostgreSQL database.
