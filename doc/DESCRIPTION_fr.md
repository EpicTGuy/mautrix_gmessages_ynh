Passerelle Matrix pour Google Messages, basée sur la passerelle officielle [mautrix-gmessages](https://github.com/mautrix/gmessages) (Go, bridgev2).

Elle relaie les conversations SMS, MMS et RCS d'un téléphone **Android** utilisant l'application Google Messages, comme messages.google.com. Le téléphone doit rester connecté.

La passerelle est un service d'application Synapse et repose sur une base PostgreSQL.
